# DonaApp

Proyecto APT desarrollado para la carrera de Ingeniería Informática.

DonaApp es una aplicación móvil orientada a facilitar la donación de objetos usados entre personas, permitiendo conectar a usuarios que poseen artículos que ya no utilizan con personas interesadas en recibirlos.

## Objetivo

Desarrollar una aplicación móvil que permita publicar, buscar, solicitar y gestionar objetos disponibles para donación mediante una solución conectada a una base de datos.

## Tecnologías utilizadas

- Kotlin
- Android Studio
- Firebase Authentication
- Firebase Realtime Database
- Git y GitHub

## Estado actual

Proyecto en desarrollo bajo un enfoque iterativo e incremental.

Actualmente se ha trabajado en la estructura de la aplicación, registro y autenticación de usuarios, diferenciación de tipos de usuario, navegación entre interfaces y selección de imágenes para la publicación de objetos.

Las funcionalidades restantes serán incorporadas progresivamente de acuerdo con el alcance definido para el Producto Mínimo Viable (PMV).
