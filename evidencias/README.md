# Evidencias de avance - DonaApp

Esta carpeta contiene evidencias correspondientes al desarrollo del Proyecto APT DonaApp.

Las evidencias incluyen avances relacionados con:
- Desarrollo y programación de la aplicación móvil.
- Integración con Firebase Authentication.
- Persistencia de datos mediante Firebase Realtime Database.
- Ejecución de funcionalidades implementadas.
- Control de versiones y documentación del proyecto.
